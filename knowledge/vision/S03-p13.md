[Figure: Figure 10] Two side-by-side bar charts labeled (a) and (b) showing sorted mean NMC values from permutation tests. Both plots have a horizontal axis labeled "permutation number" with tick marks at 0, 20, 40, 60, 80, and 100, and a vertical axis labeled "mean NMC". In plot (a), the vertical axis has tick marks at 0, 0.5, 1, 1.5, and 2; a single blue bar at permutation number 0 is labeled with the value 0.811, while grey bars for permuted data (permutation numbers 1 to 100) increase monotonically from approximately 1.5 to above 2. In plot (b), the vertical axis has tick marks at 0, 2, 4, 6, 8, 10, and 12; a single blue bar at permutation number 0 is labeled with the value 1.507, while grey bars for permuted data increase monotonically from approximately 8 to above 12.
