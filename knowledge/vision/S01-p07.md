[Figure: Multispectral Fiber System] A schematic diagram illustrating a "Multispectral Fiber System". On the right side inside the main enclosure is a box labeled "Modular System" containing four sub-modules, each displaying an icon of a spectral plot: "Raman", "FTIR", "Fluorescence", and "NIR". Lines from all four sub-modules converge and exit the bottom of the enclosure into a "Multispectral fiber probe of customised structure", which is immersed alongside a stirrer in a reaction vessel filled with blue liquid. Inside the main enclosure, the "Modular System" also connects via an arrow to a box labeled "Chemometric analysis of data fusion", which points down to a box labeled "Feedback", which in turn points down via an arrow outside the enclosure to a laptop computer displaying a spectrum on its screen.
