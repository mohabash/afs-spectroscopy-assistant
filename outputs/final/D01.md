### Requirements
Stated by the client:
- Powder blend containing API and excipients.
- Laboratory results arrive after material passes through the press.
- Pilot comparison before production-equipment commitment.

Unknown:
- API identity, concentration range and formulation variants.
- Required concentration error, reporting interval and action following an excursion.
- Reference assay uncertainty, powder variation and available feed-frame access.

### Clarification questions
1. What action should an excursion trigger, and what error and reporting interval are acceptable? Why it matters: if material diversion is intended, the trial must test measurement-to-diversion timing.
2. Which API, concentration range and excipients must the pilot cover? Why it matters: if excipients obscure the API signal, the preferred method or calibration sample set changes.
3. Which laboratory assay measures API, with what uncertainty? Why it matters: if assay uncertainty exceeds the required measurement error, the reference procedure needs improvement.
4. How do particle size, moisture, temperature and formulation vary? Why it matters: if these vary independently of API, the sample set must separate physical changes from concentration changes.
5. What feed-frame ports, powder-contact conditions and cleaning arrangements are available? Why it matters: if powder intermittently leaves the window, probe placement and invalid-spectrum detection become essential.

### Recommendation
The application example supports comparison, not guaranteed performance for your formulation. It describes process feed-frame monitoring with NIR and Raman. [S01 p.15](/materials/S01_Multispectral_Laboratory.pdf#page=15)

| Method | Why test it | Check first |
|---|---|---|
| NIR diffuse reflection | Suits scattering powders; overlapping molecular bands provide composition information. [S01 p.10](/materials/S01_Multispectral_Laboratory.pdf#page=10) | API contrast against excipients; formulation-specific chemometrics. |
| Raman | Offers complementary vibrational information; the feed-frame example uses 785 nm laser excitation. [S01 p.15](/materials/S01_Multispectral_Laboratory.pdf#page=15) | Weak API signal and fluorescence background. [S01 p.11](/materials/S01_Multispectral_Laboratory.pdf#page=11) |

Prefer whichever single method meets the agreed requirements. Test combined predictions only if neither alone suffices or fusion demonstrably improves held-out performance.

### Measurement concept
Use a diffuse-reflection NIR probe and a Raman powder probe; both geometries suit powders. [S01 Table 1 (p.6)](/materials/S01_Multispectral_Laboratory.pdf#page=6)

As a provisional installation concept, place the selected interface where moving powder consistently covers its window. Establish representativeness against matched laboratory samples. For any combined trial, align sampling location and acquisition timing. [S01 p.8](/materials/S01_Multispectral_Laboratory.pdf#page=8)

### Spectral range
Screen NIR molecular overtone and combination bands within the nominal 780–2500 nm region. [S01 p.10](/materials/S01_Multispectral_Laboratory.pdf#page=10) The listed VIS-NIR silica family ends at 2400 nm, so it cannot deliver that entire nominal range. [S02 p.6](/materials/S02_AFS_Process_Control_Slides.pdf#page=6)

For Raman, test laser excitation at 785 nm. [S01 p.15](/materials/S01_Multispectral_Laboratory.pdf#page=15) Establish useful Raman shifts in cm⁻¹ from client spectra; then verify collection-wavelength coverage for the actual components.

### Risks and uncertainty
- In general, powder packing, particle size, moisture and temperature can mimic composition changes; screening must vary them independently.
- The local probe signal may miss segregation elsewhere in the feed frame.
- Window deposits or intermittent powder coverage may replace representative spectra with misleading signals.
- A new formulation needs reference data and validation, not assumed calibration transfer.
- Reference uncertainty limits quantitative conclusions. AFS must confirm component coverage, fiber routing, mounting and cleaning compatibility.

### Feasibility plan
1. Lab screening: Measure representative client blends by both methods, spanning API concentration and expected physical variation.
2. Reference comparison: Obtain independent API assays on the same samples. Validate single-method models on held-out batches before considering fusion.
3. In-line trial: Test the selected geometry under real feed-frame conditions, matching spectra with reference samples and recording operating changes.
4. Scale-up: Integrate reporting and process actions; define model monitoring, reference checks and recalibration triggers.

**Decision basis:** Proceed only if held-out and in-line results meet client-agreed error, timing and robustness criteria.
