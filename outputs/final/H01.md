### Requirements
Stated by the client:
- Existing NIR pilot measures API concentration at the tablet press feed frame.
- Different API and excipient blend planned.
- Reuse of the calibration proposed, with Raman added.

Unknown:
- Process decision, current failure cost, and acceptable prediction error.
- New API identity, excipients, concentration range, and powder variability.
- Existing model coverage, spectral range, and reference-assay uncertainty.
- Feed-frame access and operating conditions.

### Clarification questions
1. What decision will predictions drive, and what errors cost most? Why it matters: if predictions control rejection, validation must cover incorrect acceptance and rejection.
2. Which API, excipients, and concentration range will change? Why it matters: if their spectra differ, the old model may require replacement.
3. What particle-size, moisture, temperature, and flow changes are expected? Why it matters: if these vary independently, the sample set must separate them from concentration.
4. Which independent API assay is available, with what uncertainty? Why it matters: if assay uncertainty exceeds the required error, it cannot demonstrate that performance.
5. What spectra, model files, and feed-frame access are available? Why it matters: if probe positions differ, paired measurements may sample different powder populations.

### Recommendation
In expert assessment, treat the existing calibration as unvalidated for the new formulation. Adding Raman changes the predictors; it cannot establish the old model’s validity.

### Measurement concept
Retain NIR diffuse reflection at the feed frame as the baseline interface, consistent with the application example. [S01 p.15](/materials/S01_Multispectral_Laboratory.pdf#page=15)

For comparison, align Raman and NIR sampling location and acquisition timing; multispectral measurements require spatial and temporal alignment. [S01 p.8](/materials/S01_Multispectral_Laboratory.pdf#page=8)

Confirm actual fiber transmission against the selected wavelengths before specifying the link.

### Spectral range
The nominal NIR region is 780–2500 nm; formulation-specific useful bands remain unknown. [S01 p.10](/materials/S01_Multispectral_Laboratory.pdf#page=10) Listed VIS–NIR silica ends at 2400 nm, so full nominal coverage cannot be assumed. [S02 p.6](/materials/S02_AFS_Process_Control_Slides.pdf#page=6)

Test Raman with laser excitation at 785 nm, as in the feed-frame example. [S01 p.15](/materials/S01_Multispectral_Laboratory.pdf#page=15) Establish useful Raman shifts separately, in cm⁻¹, from screening.

### Risks and uncertainty
In expert assessment, the main failure mechanisms are:
- New excipient bands could produce plausible but wrong old-model predictions.
- Particle size, packing, moisture, or temperature could mimic concentration changes.
- Feed-frame segregation could make laboratory samples unrepresentative.
- Reference uncertainty limits demonstrable prediction performance.

AFS must confirm component compatibility, mounting, sampling representativeness, and achievable performance.

### Feasibility plan
1. Lab screening: measure representative old and new formulation samples with NIR and Raman. Vary concentration independently from expected physical variation.
2. Reference comparison: independently assay the same samples. Test the frozen old NIR model first; then develop new single-method models and validate on held-out batches. Test fusion only for additional value.
3. In-line trial: compare the selected configuration against matched reference samples during actual feed-frame operation, including anticipated disturbances.
4. Scale-up: integrate the validated model with out-of-domain checks, reference monitoring, and formulation-specific recalibration procedures.

**Decision basis:** retain, rebuild, or combine methods only when held-out and in-line results meet client-agreed error, robustness, and operating requirements.
