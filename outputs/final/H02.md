**Decision status:** provisional assessment. Test NIR transmission/transflection on whey and diffuse reflection on concentrate, then compare interfaces on matched samples.

**Premise check:** The materials support comparing these interfaces across clear and opaque dairy streams, but not assuming one geometry suits both. [S01 p.18](/materials/S01_Multispectral_Laboratory.pdf#page=18)

### Requirements
Stated by the client:
- Relatively clear whey and opaque milk concentrate.
- Composition-monitoring pilot.
- Laboratory protein and fat results where relevant.
- Interface comparison before installation.

Unknown:
- Process decisions, current losses, and required measurement performance.
- Relevant constituents and concentration ranges for each stream.
- Temperature, solids, bubbles, and homogenization changes.
- Laboratory methods and their uncertainty.

### Clarification questions
1. What goes wrong today, what does it cost, and what action would monitoring trigger? Why it matters: if only trend alarms are needed, evaluate those before quantitative control.
2. Which constituents, concentration ranges, acceptable errors, and update intervals matter for each stream? Why it matters: if whey fat varies below measurable spectral contrast, NIR may not answer that target.
3. How do temperature, solids, homogenization, and bubbles vary? Why it matters: if scattering changes independently of composition, the sample set must separate those effects.
4. Which laboratory assays, uncertainties, and sampling procedures provide protein and fat results? Why it matters: if reference uncertainty exceeds the required error, the pilot cannot demonstrate that requirement.
5. Which pipe or bypass locations, cleaning conditions, and analyzer distances are available? Why it matters: if deposits cover the window, the interface and cleaning concept must change.

### Recommendation
Start with NIR alone. The dairy application description supports protein and fat modelling, but does not establish performance for these streams. [S01 p.17–18](/materials/S01_Multispectral_Laboratory.pdf#page=17)

### Measurement concept
Use a transmission/transflection gap for whey and a windowed backscatter interface for concentrate; these geometries match the listed sample types. [S01 Table 1 (p.6)](/materials/S01_Multispectral_Laboratory.pdf#page=6)

As an expert proposal, compare interfaces on matched aliquots before testing a pipe-mounted or bypass installation. Establish path length experimentally. Confirm mounting, cleaning compatibility, and fiber routing with AFS.

### Spectral range
NIR contains overlapping O–H, N–H, and C–H-related bands across the nominal 780–2500 nm region; quantitative analysis requires chemometrics. [S01 p.10](/materials/S01_Multispectral_Laboratory.pdf#page=10)

VIS-NIR silica fibers are listed to 2400 nm, so they do not support claiming the full nominal upper range. Select useful bands within confirmed component coverage. [S02 p.6](/materials/S02_AFS_Process_Control_Slides.pdf#page=6)

### Risks and uncertainty
- Whey transmission can lose signal if the path is unsuitable; concentrate reflection responds to fat-globule size. [S01 p.17–18](/materials/S01_Multispectral_Laboratory.pdf#page=17)
- In general, temperature, bubbles, and deposits can mimic composition changes; challenge them independently during screening.
- Treat each stream as a separate calibration domain until transfer is demonstrated.
- Reference uncertainty limits demonstrable prediction performance. Actual component coverage and installation details need AFS confirmation.

### Feasibility plan
1. Lab screening: Measure representative client samples with each candidate interface. Span composition and physical variation; compare spectra, repeatability, and usable transmission.
2. Reference comparison: Obtain independent protein and fat assays on the same samples where relevant. Compare interface-specific models using held-out batches, not repeated aliquots alone.
3. In-line trial: Install the selected interface for each stream. Challenge flow changes, bubbles, temperature excursions, and cleaning cycles against matched laboratory samples.
4. Scale-up: Integrate validated outputs with the intended process decision. Define drift checks, new-product validation, and recalibration responsibilities.

**Decision basis:** Proceed only if held-out and in-line results meet client-agreed analytical, operational, and economic criteria.
